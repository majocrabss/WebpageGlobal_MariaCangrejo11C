## How to Test C9 Mode — Three CSV Files

### Dataset 1 (dataset_1.csv) — Mean test
1. Go to the **C9** tab
2. Upload `dataset_1.csv`
3. **Data Type** → Mean
4. **Group Column** → `group`
5. **Value Column** → `score`
6. **Benchmark Group** → `Control` · **Test Group** → `Treatment`
7. Direction: **Right-tailed** · α = 0.05
8. Click **Run Hypothesis Test**

✅ Expected: z ≈ 11.88, p < 0.0001 → **Reject H₀**

---
